Esquema estrela montado a partir de um arquivo exemplo da Microsoft "Financial sample".

As tabelas a seguir foram criadas com base na tabela original de Financial Sample, de modo que um esquema estrela pudesse ser montado.

Foram utilizadas as funções de agrupamento de linhas (para formulação de tabelas filtro) e 
formatação condicional de colunas (para inserção de um ID compartilhado entre tabelas) para a construção das tabelas.

Fato - Vendas
Dimensão - Produtos
Dimensão - Produtos_detalhes
Dimensão - Descontos
Dimensão - Detalhes

Enquanto a tabela Dimensão - Data foi criada com as formulas DAX "Calendar()", "Quarter()" e "Year()", para diferentes visualizações.
